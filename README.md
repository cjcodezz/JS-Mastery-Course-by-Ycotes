# JS Mastery Course by Ycotes

Welcome to the **JS Mastery course** — a complete JavaScript learning path from basic fundamentals to advanced practical code. This project follows the full JS Mastery flow with real code examples, live demo pages, and hands-on practice.

## Course Overview

This course is built to teach JavaScript with clear explanations and practical examples:

- Learn how JavaScript variables and data types work.
- Understand conditionals, loops, and logic building.
- Master functions, callbacks, closures, and recursion.
- Use arrays, objects, destructuring, and JSON.
- Manipulate the DOM with live browser interaction.
- Explore modern ES6+ features like Promises and async/await.
- Practice with project-ready snippets and page demos.

## Modules included in this course

- **Module 1:** JavaScript Basics and Setup
  - What JavaScript is
  - Running code in the browser
  - Basic syntax and comments
  - Simple examples for learners

- **Module 2:** Variables and Data Types
  - `var`, `let`, `const`
  - Primitive vs non-primitive values
  - Operators and expressions
  - Template literals
  - Type conversion and coercion

- **Module 3:** Control Statements and Loops
  - `if-else` conditions
  - `switch` statements
  - `for` loops
  - `while` and `do-while` loops
  - Nested loops and logic building

- **Module 4:** Functions
  - Function declarations
  - Arrow functions
  - Callback functions
  - Closures
  - Higher-order functions
  - Recursion

- **Module 5:** Arrays and Objects
  - Array methods
  - Object properties
  - Destructuring
  - Spread operator
  - JSON handling

- **Module 6:** DOM Manipulation
  - DOM structure and element selection
  - Changing content and styles
  - Event listeners
  - Form handling

- **Module 7:** ES6+ Features
  - Promises
  - Async/await
  - Modules
  - Optional chaining
  - Default parameters

## What you will learn

- `var`, `let`, `const`
