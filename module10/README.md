# Module 10: JavaScript Projects

This folder contains starter files for Module 10 project examples.

Files included:

- `calculator.js` - simple calculator logic with add, subtract, multiply, divide, and expression parsing.
- `todo.js` - basic to-do list manager with add, toggle, remove, and list functions.
- `quiz.js` - quiz question data, answer checking, and score calculation.
- `weather.js` - async weather lookup simulation and weather formatting.
- `portfolio.js` - portfolio project list and helper functions for rendering or selection.

You can build HTML demo pages around these modules and connect them to UI controls.
